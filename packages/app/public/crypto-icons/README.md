# Crypto currency icons

`btc.svg` … `dai.svg` are vendored from
[spothq/cryptocurrency-icons](https://github.com/spothq/cryptocurrency-icons)
(CC0 1.0 / public domain), served from our own origin to keep the app
CDN-free — same policy as `public/flags`.

`near.svg`, `arb.svg`, and `op.svg` are simple ticker badges drawn in-repo
(the upstream set predates those coins).
