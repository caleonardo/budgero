Budgero est conçu pour être utilisé au clavier. La liste complète est toujours à un clic : le bouton **clavier** dans l'en-tête ouvre **Raccourcis clavier** dans l'application.

Les touches s’affichent selon votre ordinateur : <kbd>⌘</kbd> <kbd>⌥</kbd> <kbd>⇧</kbd> sur un Mac, <kbd>Ctrl</kbd> <kbd>Alt</kbd> <kbd>Shift</kbd> ailleurs. Les raccourcis sont ignorés pendant que vous tapez dans un champ : ils ne gênent donc jamais votre saisie.

## Avec des lignes sélectionnées

<table>
  <thead>
    <tr>
      <th>Touches</th>
      <th>Action</th>
    </tr>
  </thead>
  <tbody>
    <tr><td><Keys>G</Keys></td><td>Changer la catégorie</td></tr>
    <tr><td><Keys>M</Keys></td><td>Déplacer vers un autre compte</td></tr>
    <tr><td><Keys>P</Keys></td><td>Définir le bénéficiaire</td></tr>
    <tr><td><Keys>C</Keys></td><td>Marquer comme pointées, ou comme non pointées si elles le sont déjà toutes</td></tr>
    <tr><td><Keys>Shift+D</Keys></td><td>Dupliquer</td></tr>
    <tr><td><Keys>Delete</Keys></td><td>Supprimer — la confirmation comporte un bouton Annuler</td></tr>
  </tbody>
</table>

<Keys>G</Keys>, <Keys>M</Keys> et <Keys>P</Keys> ouvrent un sélecteur dont la recherche est déjà active : tapez quelques lettres, appuyez sur <Keys>Enter</Keys>, et la modification s'applique à toutes les lignes sélectionnées. <Keys>Esc</Keys> ferme le sélecteur sans rien modifier. <Keys>C</Keys> ignore les lignes rapprochées.

## Ajouter une transaction

<table>
  <thead>
    <tr>
      <th>Touches</th>
      <th>Action</th>
    </tr>
  </thead>
  <tbody>
    <tr><td><Keys>Tab</Keys> / <Keys>Shift+Tab</Keys></td><td>Passer d'un champ à l'autre</td></tr>
    <tr><td><Keys>Enter</Keys></td><td>Enregistrer (depuis un champ de texte)</td></tr>
    <tr><td><Keys>Ctrl+Enter</Keys></td><td>Enregistrer depuis n'importe quel champ</td></tr>
    <tr><td><Keys>Esc</Keys></td><td>Fermer sans enregistrer (ligne en place)</td></tr>
  </tbody>
</table>

Dans la ligne en place, <Keys>Enter</Keys> sur un bouton active ce bouton — Ventiler, Annuler ou un sélecteur — au lieu d'enregistrer.

## Champs de montant

Les champs de montant sont des calculatrices : tapez `120 + 35` ou `300 / 3` et c'est le résultat qui est enregistré. Ces raccourcis fonctionnent pendant la modification d'un montant :

<table>
  <thead>
    <tr>
      <th>Touches</th>
      <th>Action</th>
    </tr>
  </thead>
  <tbody>
    <tr><td><Keys>Ctrl+H</Keys></td><td>Diviser le montant par deux</td></tr>
    <tr><td><Keys>Ctrl+D</Keys></td><td>Doubler le montant</td></tr>
    <tr><td><Keys>Ctrl+T</Keys></td><td>Prendre 10 %</td></tr>
    <tr><td><Keys>Ctrl+Z</Keys></td><td>Mettre à zéro</td></tr>
    <tr><td><Keys>Enter</Keys></td><td>Enregistrer le montant</td></tr>
    <tr><td><Keys>Esc</Keys></td><td>Annuler la modification</td></tr>
  </tbody>
</table>

Pour trouver des transactions plutôt que de vous déplacer entre elles, consultez [Rechercher des transactions](/docs/semantic-search).
