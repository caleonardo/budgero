# SEO fixes — September 5, 2026

Implemented the confirmed code and content corrections from the [September 4 audit](2026-09-04-audit.md). These changes are committed locally; deployment and Google's subsequent recrawl are separate steps. They do not establish the cause of the recent traffic decline or predict a recovery date.

## What changed

| Area | Result |
|---|---|
| Blog canonical | `/blog` now has its own canonical, title, description, and social metadata. The root layout no longer supplies a homepage canonical to child routes. |
| Sitemap coverage | Added `/blog` and `/donate`. Published article URLs remain included; drafts and unpublished articles are excluded consistently. |
| Sitemap dates | Removed filesystem modification times and deployment-time fallbacks. Articles use editorial publication/update dates; changelog dates are interpreted in UTC. Other pages omit `lastmod` where no editorial date is recorded. |
| Internal links | The homepage links to encrypted budgeting and international comparisons; the blog links to zero-based budgeting; the alternatives guide links to the Goodbudget, PocketGuard, and Simplifi comparisons. All five previously orphaned pages now have incoming links. |
| Retired documentation | `/docs/budgero-core-vs-cloud` permanently redirects to `/self-hostable`. Existing relevant redirects remain intact. |
| Blog structure | Removed duplicate H1s from five articles. Article templates show the Budgero byline and an explicit updated date when provided. |
| Structured data | Removed the nonexistent site-search action from the root WebSite schema. |
| App shell | Added `noindex, follow` to `packages/app/index.html`. This takes effect when the budgeting app is deployed, independently of the marketing website. |
| Documentation types | Replaced the intersected topics-array type with an explicit override, fixing the four TypeScript errors in the documentation index. |

## Comparison content

Updated `/best-ynab-alternatives`, `/vs-ynab`, `/ynab-alternative-europe`, both main Monarch alternative pages, the Goodbudget/PocketGuard/Simplifi comparisons, and the Actual Budget article.

- Corrected Actual's optional bank integrations, installable PWA, import formats, reports, and native currency-conversion limitations.
- Corrected YNAB's public API, mobile offline access, six-person sharing, encryption at rest/in transit, and selective European bank coverage. Removed unsupported withdrawal/re-entry claims and blanket assertions about sharing banking passwords.
- Updated Goodbudget Premium, PocketGuard, and Simplifi prices and qualifications; corrected Goodbudget's US Premium bank sync and Simplifi's Canadian support. Clarified PocketSmith annual billing and Lunch Money's flexible annual pricing.
- Removed unsupported legal, billing, universal bank compatibility, and migration guarantees from the revised Europe pages.
- Added official source links, page-specific review dates, and disclosure that comparisons are based on documentation. No claim of hands-on testing of every competitor or bank is made.
- Added an illustrative EUR/GBP calculation, an existing Budgero interface screenshot, and links to currency, CSV import, and YNAB migration guides. Explained preview, reconciliation, duplicate-import risks, and migration limitations.
- Clarified free self-hosting versus paid Cloud in the YNAB comparison metadata. Fixed wrapping of review dates on mobile and longer pricing notes on desktop.
